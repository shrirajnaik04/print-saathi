# Round 4 (Phases 29–32) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The owner's ten round-4 requests:
- ID cards: crop per side, Change photo, Turn left / Turn right;
- Adjust: compact tools, zoom, pages side by side;
- the Leave / Close questions, and Home without the WhatsApp card;
- Ready: the Colour | B&W toggle at the top, and paper type.

**Architecture:** All changes are in the web app (Preact/TS) except the device checks. A quarter-turned card uses the plan's existing quarter turns and quad path, which the Kotlin engine already prints. The navigation questions are a pure guard in `core/nav` plus one dialog component used by the app shell.

**Tech Stack:**
- Preact 10, TypeScript 5, CSS.
- Vitest, Playwright (Chromium, mocked engine).
- Android emulators for closure.

**Spec:** `docs/superpowers/specs/2026-10-24-round-4-cards-zoom-pages-leave-design.md`

## Global Constraints
- Offline, ₹0, **no new dependency**. New icons come from the already pinned `@phosphor-icons/core` 2.1.1.
- Customer files are parsed only in the isolated engine; no image bytes over the bridge.
- One geometry (the plan) for preview and print; exact sizes; 300 dpi at the box, never lower.
- Plain English: the jargon lint stays green, and "Margins" is the only form of "margin".
- Anything pressed is at least 56 px; every gesture has a button that does the same.
- "Remove animations" is respected. Back and Home never lose work without the shopkeeper saying so.
- Each e2e run first runs `npx vite build --mode e2e`, or uses `npm run test:e2e`.

## Review Focus
1. A share arriving while "Leave this job?" or "Close PrintSaathi?" is open: the question closes, and the share's screen (Received / New files arrived) shows as usual. Test in Task 1.
2. Delete this job on the job behind Home's Continue card: back on Home, no Continue card for it and no Recent jobs row. Test in Task 1.
3. Change photo with the picker closed without a choice, or with a photo in which no card is found: no choice leaves both sides as they were; no card found gives the card-shaped frame. Test in Task 6.
4. Drags while zoomed (the round corner, side bars, the rotate handle and press-and-hold) work in page points: at 200 % a corner drag of 40 px resizes by 40 px ÷ (2 × the 100 % scale). Test in Task 9.
5. Mixed card turns (front lying, back standing) in every size, Many copies included: every box inside the page edges, none overlapping, each the right shape. Test in Task 5 (all 16 turn pairs × 4 sizes).
