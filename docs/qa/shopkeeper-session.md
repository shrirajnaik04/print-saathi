# Session kit: can the shopkeeper do it alone? (PLAN §T1 Phase 11, §A success 1–2, §H4, §R level 11)

Print one copy of this page per person. One session with the shopkeeper, then the same with 1–2 other seniors (55–75, WhatsApp
users) if you can. About 45 minutes each.

## Before the session (you, 15 min)
1. The shopkeeper's phone has the latest PrintSaathi. The Brother Print Service Plugin (or Mopria) is enabled. The test page has been printed once on A4 and once on 4×6 (USER-CHECKLIST §I).
2. From **your** phone, send these to **The shopkeeper's WhatsApp** (you are "the customer"):
   - 7 photos (any of yours);
   - 3 more photos (for task 3);
   - 1 portrait photo of a person (yours, for passport);
   - 1 PDF with 3–5 pages;
   - your own e-Aadhaar PDF (password: first 4 letters of your name in CAPITALS + birth year).
3. Load A4 paper. Keep 4×6 glossy paper next to the printer, not in it.
4. Have this sheet, a pen and a ruler. **Do not help** unless they are stuck for 2 minutes or ask. If you help, mark that task "with help".
5. If you can, ask a second person to count the taps while you watch the person (counting while watching is hard).
6. Never photograph or keep the e-Aadhaar or its printout; shred the printout afterwards.

## The six tasks: read each request out as a customer would

| # | Say this | Done alone? | Taps inside PrintSaathi (target) | Hesitations / words not understood |
|---|---|---|---|---|
| 1 | "Print these 7 photos, all on one page, in colour." | ☐ yes ☐ with help ☐ no | ___ (2) | |
| 2 | "Print these 7 photos on more pages, so they are bigger." | ☐ yes ☐ with help ☐ no | ___ (2) | |
| 3 | "One photo on each page, please." (send 3 photos) | ☐ yes ☐ with help ☐ no | ___ (2) | |
| 4 | "5 passport photos of this, please." | ☐ yes ☐ with help ☐ no | ___ (3) | |
| 5 | "Print this PDF, black and white." | ☐ yes ☐ with help ☐ no | ___ (1) | |
| 6 | "Print my Aadhaar." (tell them the name and birth year, as a customer would) | ☐ yes ☐ with help ☐ no | ___ | |

**Before each request:** make sure PrintSaathi is on its Home screen (answer "Did it print correctly?" first). A job
left open turns the next share into a "New files arrived" question: if it appears anyway, do not count that tap, just
note it.

**How to count taps:** start after they choose PrintSaathi in WhatsApp's share list. Stop at the PrintSaathi PRINT button (Android's own print button is not counted). The Yes/No question after printing is not counted.

## After each task
- Compare the printed sheet with what Ready showed: same number of pages, same layout, same colour. ☐ same ☐ different (what?)
- Task 4: measure one passport photo: ____ × ____ mm (target 35 × 45 ± 0.5).

## At the end (ask the person)
1. "Which step was confusing?" __________________________________
2. "Were any words strange?" __________________________________
3. "Is the text big enough?" ☐ yes ☐ bigger please
4. "Would English or Marathi/Hindi be easier?" ☐ English is fine ☐ __________ (PLAN §H5)

## Pass rule (PLAN §U UX)
- **PASS:** at least 5 of the 6 tasks are done alone, and the taps for tasks 1–5 are at or under target.
- Anything else: send me this sheet (a photo is fine). Every confusing step becomes a fix.
