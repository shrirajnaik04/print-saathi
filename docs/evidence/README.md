# Evidence

Each phase's proof lives here as `docs/evidence/<phase>/<date>/`: test outputs, device results, measurements and
screenshots. The closure reports in `docs/qa/` point to them.

**Screenshots taken before 2026-10-23 are not in this public copy.** They showed earlier on-screen wording and are
kept in the project's private history; their text results, logs and JSON files are here. Screenshots from the
2026-10-23 wording change onward are included.

All test files and screenshots are synthetic: no customer's file or photo is in this repository.
